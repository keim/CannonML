# Cannon Macro Language ver0.30 コマンドリファレンス

Cannon Macro Language (CML) 簡易リファレンスです。

## 概要

```
[8 q$l*20-70,-100 da0 f10{ {[w20-$r*16 f6]} i30 dt0 ~v0 ~v-10 } w4]
```
簡単な短い文字列で2Dシューティングゲームの敵の動きを表現するスクリプトエンジンです。時間単位はフレームで指定し実装依存です。

- **CMLスクリプト**：一連のコマンドを記述した「手順書」
- **CMLオブジェクト**：敵機、弾、自機、ステージなど、ゲーム上で動作する「物」
- **CMLファイバ**：スクリプトを読んでオブジェクトを動かす「操縦者」

上記３つの概念が連携して動作します。

- **CMLスクリプト**の基本構文は `[コマンド文字列][引数],[引数]...` です。正規表現の最長一致で構文解析され、意味が確定できればコマンド間のスペースは不要です。また、引数には四則演算と`$`で始まる変数や関数を利用できます。
-  **CMLオブジェクト**は移動や旋回など基本的なパラメータを与えれば、スクリプトを記述しなくても自動で動きます。**CMLスクリプト**は、適切なタイミングでこれらのパラメータを書き換える事で複雑な動作を定義します。「パラメータ書換」→「待機」→「パラメータ書換」... が基本的な流れとなります。
- 一つの**CMLオブジェクト**は、複数の**CMLファイバ**を持つことができます。**CMLファイバ**は、**CMLスクリプト**の実行単位で、例えば「速度を変えるスクリプト」と「回転制御のスクリプト」と「弾を射出するスクリプト」を別のファイバで同時並行動作させる事ができます。

## CMLスクリプトの構成要素

### コメント

```
// コメント
/* コメント */
```

`//`に続く1行、`/* ~ */`の内部はコメントとして扱われます。

### コマンド
```
[コマンド文字列][引数],[引数]...
```
引数の数はコマンド毎に決まっていて、省略すると0が代入されます。ただし、可読性の観点から、最低一つは引数を挟む事を推奨します。

```
[コマンド文字列]([引数],[引数]...)
```

引数は `( )` で囲む関数形式でも書けます。`p(1,2)` は `p1,2` と、`v(1,2)` は `v1,2` と、`&A(10,20)` は `&A 10,20` と同じ意味です。`f(5)` `bm(3,40)` `w(2)` のように全コマンドで使えます。この仕様書では、括弧なしのニーモニック形式を基本の書き方とし、関数形式は同等の公式な書き方として扱います。

- `( )` は数式の括弧として扱われます。そのため、`p(1,2)*3` は `p1,2*3`（= `p1,6`）、`p(1+2)*3` は `p(1+2)*3`（= `p9,0`）と同じです。関数呼び出しのように引数リストだけを閉じるわけではないので、括弧の後ろに式を続けないでください。
- 括弧内の数式は `p((1+$1)*2,0)` のように入れ子にできます。括弧の内側・前後に空白を置けます（`p( 1, 2 )`）。
- `(` と `)` の数が合わない場合は構文エラーです。
- どのコマンド・引数にも解釈できない文字や数値は、無視されずに構文エラーになります（`p1 2` `p1,2 ;` など。空白・改行・コメントは除く）。

### シーケンス定義
```
#(label_name) { (commands) }
```

中括弧`{ }`内の一連の動作を定義して、後からラベル名で呼び出します。ラベル名は`/[A-Za-z0-9_]+/`です。定義したシーケンスは必ず`&(label_name)`で呼び出します。`&`を付けずにラベル名だけを記述した場合は構文エラーになります。

## 制御構文

### 繰り返し ([...])

```
[ [ループ回数] (commands) ]
```

(loop) 引数で指定した回数、[...]内を繰り返し実行します。ループ回数に数式を用いた場合、ループに入った最初の1回だけ計算されます。ループ回数が0または未指定の場合、永久ループします。

### 条件分岐 ([?...:...])

```
[ [式] ? (commands) : [式] ? (commands) : (commands) ]
```

(if ... else if ... else ...) 引数で指定した条件式により分岐します。[式]が非０なら ":"以前、０なら ":"以降のシーケンスが実行された後 `[...]`を出ます。

### 並列実行 ({...})

```
{ (commands) }
```

コマンド列の中に `@x @o @ko f fs` の指定が無く `{ }`(シーケンス)が記述されていた場合、中括弧内を新規ファイバで実行します。例えば `{da0 v10 w30 v-10} {[w5 f10]}`は、上下の動きと弾射出を並列実行します。`{...}` `{.}` は引数を取れません（後ろに引数を書くと構文エラー）。引数を渡せるのは `&(label_name)` だけです。

### シーケンス呼出 (&)

```
&(label_name)
```

`#(label_name) { (commands) }` で定義したシーケンスを実行します。並列実行したい場合は`{&(label_name)}`と中括弧で囲ってください。

```
&(label_name) [引数], [引数] ...
```

引数を指定すると、呼び出し先の `$1`〜`$9` に順番に格納されます。例えば `#A{p$1,$2} &A 10,20`（関数形式では `&A(10,20)`）は、位置を (10, 20) に設定します。

## 待機

```
w [待機フレーム数]
```

(Wait) 引数で指定したフレーム数待機します。引数を省略した場合、前回指定したフレーム数と同じだけ待機します。`w0`は待機せず、次のコマンドに移動します。

```
w? [式]
```

(Wait if) 引数で指定した [式] が 0 になるまで待機します。`v0,5 w?$t.y<$y v$sy*-5,0` で、自機のy座標まで下移動した後、画面中央に向かって横移動します。

## オブジェクト制御

オブジェクトを動かすコマンド群です。`p`位置，`v`速度，`a`加速度，`r`旋回のコマンドがあります。これらのコマンドは、`i` で遷移時間を設定し、`d*` で方向を設定します。

### パラメータ補間時間設定 (i)

```
i [補間フレーム数]
```

(Interpolate) パラメータ変化にかかる時間を指定します。`p` `v` `pz` `vz` `r` `rx` `ry` で参照されます。`a` には影響しません。例えば `i30 v10` は 30フレーム後に速度10になるように加速度が付与されます。また、`i30 p10,20 v5` のように `p` と `v` を同時に指定した場合、30フレーム後に(10, 20)の位置で速度5になるように3次ベジェ補間します。`i0`で即時変更になります。

### パラメータ補間時間設定＆待機 (~)

```
~ [補間・待機フレーム数]
```

(interplate and wait) `i` と `w` を実行する簡略化コマンドです。`~10 v5` は `i10 v5 w10` と実行されます。また、引数を省略した場合は `i` 指定値が採用されます。例えば `i60 ~ p10,0 ~ p-10,0`は、`i60 p10,0 w60 p-10,0 w60` と実行されます。

### 方向設定 (d*)

様々なコマンドの角度をDegree単位（反時計回りが正）で指定します。`p` `v` `a` `r` `f` `fs` で参照されます。このコマンドは実行時に角度を算出します。例えば `dt0 w10 f` は、10フーレム前にターゲットへの角度を算出するため、正確にターゲットに向けて射出されません。`w10 dt0 f` と、同フレームで角度指定してください。

```
da [角度]
```

(Direction by Absolute angle) スクリーン上の絶対角度(スクロール方向を0)で指定します。

```
dt [角度]
```

(Direction to Target) ターゲット（デフォルトではプレイヤー）方向との相対角度で指定します。

```
do [角度]
```

(Direction relative to Object angle) オブジェクト角度との相対角度で指定します。

```
dv [角度]
```

(Direction based on Velocity vector) オブジェクト進行方向との相対角度で指定します。

```
dp [角度]
```

(Direction relative to Parent angle) 親オブジェクトの角度（向き）との相対角度で指定します。`fs` で生成した相対位置の子オブジェクトでは親の角度を基準にし、`f` で生成した子オブジェクトでは画面の 0 度（スクロール方向）を基準にします。

```
ds [角度]
```

(Direction changing Ssequencially) 現在の角度設定値からの相対角度で指定します。

### 位置 (p*)

```
p [指定角度方向距離], [指定角度垂直方向距離]
```

(Position) `d*`コマンドで指定した方向を基準としてオブジェクトの位置を設定します。引数省略で 0 が設定されます。

```
pz [z座標]
```

(Position Z) オブジェクトのz座標を指定します。xy 座標とは独立して補間します。

このコマンドは`i`指定値の影響を受けます。`i0`の場合は即時変更し、値が指定されている場合は、３次スプライン補間によって`i`指定の時間をかけて指定位置まで移動します。このコマンドに続いて`v`を指定した場合，３次スプライン補間の終点速度になります。

### 速度 (v*)

```
v [指定角度方向速度], [指定角度垂直方向速度]
```
(Velocity) `d*`コマンドで指定した方向を基準としてオブジェクトの速度を設定します。引数省略で 0 が設定されます。

```
vz [z速度]
```

(Vwlocity Z) オブジェクトの速度のz成分を指定します。xy 速度とは独立して補間します。

`i`指定値の影響を受けます。`i0`の場合は即時変更し、値が指定されている場合は、３次スプライン補間によって`i`指定の時間をかけて指定速度まで加減速します。同一フレーム内で `p` を指定したs場合，３次スプライン補間の終点速度になります。

### 加速度 (a*)

```
a [指定角度方向加速度] 、 [指定角度垂直方向加速度]
```

(Velocity) `d*`コマンドで指定した方向を基準としてオブジェクトの加速度を設定します。引数省略で 0 が設定されます。

```
az [z加速度]
```

(Accelaration Z) オブジェクトの加速度のz成分を指定します。

`i`指定値の影響は**受けません**。加速を停止させるには、`a0`を指定するか、(変遷時間を指定した)`p`または`v`を指定します。

### 旋回 (r*)

```
r [開始速度], [終了速度], [最大角度]
```

(Rotation) オブジェクトを`d*`で指定した方向まで`i`指定フレーム数かけて旋回します。`i0`の場合、即時変更します。[開始速度] / [終了速度] は，等速回転した場合の回転速度を1とした相対値で指定します。例えば、`r0,0` の場合、開始角速度0から、加速→中央で最高速旋回→減速、終了時の角速度0となるように補間されます。`r1,1`の場合、等速回転します。`r2,0`の場合，等加速度回転です。`r-1,0`の場合，開始時は反対方向に旋回し，加速→減速、終了時の角速度は0となるように補間されます。[最大角度] は、現在の角度と`d*`指定角度の差分に対して最大絶対値を設定します（無指定 or 0 なら角度制限しません）。例えば `[dt0 r1,1,1 w1]` で、最大角速度 1度/Frame でターゲットに向けて旋回します。

```
rx [角度], [開始速度], [終了速度]
```
```
ry [角度], [開始速度], [終了速度]
```

(Rotation X/Y) X/y軸を軸に指定角度まで`i`指定フレーム数かけて旋回します。第２/３引数は、`r`の第１/２引数と同等です。各軸の回転は独立して計算されます。

## オブジェクト生成

`f`で初速度を指定して子オブジェクトの生成します。`fs`は生成元オブジェクトを原点とした相対位置に子オブジェクトを生成します。子オブジェクトは `q` `qx` `qy` で指定した位置を初期位置として生成します。また、`bm` `bs` `br` で、同時生成するオブジェクト数を設定します。

### 原点の指定 (q*)

```
q [x座標], [y座標]
```

原点を指定します。引数省略で 0 が設定されます。

```
qx [x座標]
```
```
qy [y座標]
```

原点の x または y座標のみを指定します。

`f` で生成される子オブジェクトの初期位置、および `d*` で算出する角度の原点を指定します。この原点は、オブジェクトの相対位置として扱われるため、オブジェクトが回転すると角度にあわせて位置が移動します。例えば `q0,0 dt0 q-5,0 f10 q5,0 f10` と指定すると、「オブジェクトの中心からターゲットに向かって計算した角度で、原点のx座標を-5/+5した位置から弾速10の弾二つを射出」します。また、`q-5,0 dt0 f10 q5,0 dt0 f10` だと、「原点のx座標を-5/+5した位置から弾速10の弾二つをターゲットに向かって射出」します。

### 複数オブジェクト生成コマンドの設定 (b*)

```
bm [弾数], [扇中心角], [速度範囲], [連射間隔]
```

(Barrage setting Multiple) `f` コマンドの同時射出を扇状弾中心角/多重弾速度幅/連射間隔で指定します。

```
bs [弾数], [角度増減値], [速度増減値], [連射間隔]
```

(Barrage setting Sequencial) `f` コマンドの同時射出を1射出毎の角度増減値/速度増減値/連射間隔で指定します。

```
br [弾数], [角度範囲], [速度範囲], [連射間隔]
```

(Barrage setting Random) `f` コマンドの同時射出を乱数弾角度範囲/乱数弾速度範囲/連射間隔で指定します。

このコマンドを指定後，一回の `f` `fs` コマンドで，扇状弾/多重弾/連射弾/乱数弾を一度に射出するようになります。以下２つの特殊な記法があります。
- [扇中心角]=-360/+360を指定した場合，全方位弾として計算されます。
- `bs` `br` コマンドで [弾数]=0 かつ [連射間隔]\>0 の場合、`kf`(全ファイバ破棄)か、オブジェクトが破壊されるまで連射して続けます。

`bm` `bs` `br` コマンドは連続して記述することで，階層的に弾幕を設定する事が可能です。例えば `bm3,30 bm5,0,2` と記述した場合，一回の`f`コマンドで，速度幅2の多重弾5発が，中心角30度で3方向に射出されます。`br5、90、0、10bm4、10` と記述した場合，中心角10度の扇状弾4発が，90度の範囲でランダムに10フレ間隔で5連射されます。

### オブジェクト生成 (f*)

```
f [速度], [オブジェクトID] ( {(sequence)} | &(label_name) )
```

(Fire) 初速度を指定して子オブジェクトを生成します。

```
fs [速度], [オブジェクトID] ( {(sequence)} | &(label_name) )
```

(Fire Static child) 初速度を指定して子オブジェクトを生成します。このコマンドで生成されたオブジェクトは親の相対位置に配置されます。

`f` コマンドは、`b*` で指定した数のオブジェクトを生成します。オブジェクトは指定した初速度が与えられます。このコマンドの直後に `{(sequence)} | &(label_name)` を指定すると、最初からシーケンスが設定されたオブジェクトを生成します。例えば `f5 { a0.1 }` で、加速度=0.1 を持った初速 5 の弾が射出されます。`&(label_name)` に引数を指定した場合（`f0 &A 4`）は、生成されたオブジェクトの `$1`〜`$9` に格納されます。`{...}` では引数を指定できません。

## 特殊ファイバ起動

通常、新規ファイバは `{...}` で起動しますが、`@x` `@m` `@o` `@ko` を指定すると特殊なファイバを起動・設定できます。

### 排他的ファイバ起動 (@x)

```
@x [排他実行ID] ( {(commands)} | &(label_name) )
```

(run fiber eXclusive) 排他的にファイバを起動します。このコマンドでファイバ起動した場合、同じ[排他実行ID]を持った起動中のファイバを停止してから、新たなファイバを起動します。例えば `@x1{[dt0 f10 w2]} w60 @x1{dt a-0.2}` は、連射ファイバ `{[dt0 f10 w2]}` を60フレーム実行後、連射を止めて逃避ファイバ `{dt a-0.2}`を起動します。

### ミラーファイバ起動 (@m)

```
@m ( {(commands)} | &(label_name) )
```

(run fiber Mirror) このコマンドで起動したファイバを、スクロール軸を対称軸として反転します。反転は、起動したファイバが終了するまで続きます（`w` `~` を挟んでも解除されません）。`p` `v` `a` `q` `d*` `b*` の位置・方向が反転します（`q` `qx` `qy` は画面座標で、スクロール軸に垂直な画面軸の値を反転します。縦スクロールでは x、横スクロールでは y）。`dt` は常にターゲットを狙い、オフセット角だけが反転します。`&` `f` `fs` `@x` `@o` `@ko` で起動したファイバも全コマンドが反転します。`@m` の中でさらに `@m` を使うと、反転は打ち消されます。

### 子オブジェクトファイバ起動 (@o)

```
@o [子オブジェクトID] ({(commands)}|&(label_name))
```

(run fiber on child Object) `f` `fs` コマンドの第二引数でIDを指定した子オブジェクトに対して，新規ファイバを起動します。@oコマンドでは，補助コマンドのパラメータは常にリセットされます。また，[排他実行ID]の指定は出来ません。

### オブジェクト破棄時に起動するファイバ設定 (@ko)

```
@ko [終了ステータス] ({(commands)}|&(label_name))
```

(run fiber when Killing Object) 指定した[終了ステータス]でオブジェクトが破棄された時に、ファイバを起動します。[終了ステータス]は koコマンド または CMLObject.destroy() の引数で指定した値です。このシーケンスは1フレームのみ実行されます。`w`や`~` のような待機時間指定コマンドは実行されず，以降のシーケンスは無視されます。

## その他

### オブジェクト破棄 (ko)

```
ko [終了ステータス]
```

(Kill Object) このコマンドが呼び出されたオブジェクト自身を破棄します。[終了ステータス]で指定した数字が `@ko` で定義されていた場合、終了時に終了シーケンスが走ります。

### 全ファイバ停止

```
kf
```

(Kill all Fibers) このコマンドを実行したファイバが生成したすべての子ファイバを強制終了します。ただし `@o` で子オブジェクト上に起動したファイバは対象外で、停止しません。特定の排他実行IDを持つファイバのみを終了させたい場合は，"@x1{}" のように空のシーケンスで上書きしてください。

### シーケンスの再呼出

```
{.}
```

(same seq as previous call) 前回利用したシーケンスを再参照します。前回呼び出したシーケンスは Fiber 毎に２つ(ファイバ起動用、オブジェクト生成用)保存されます。


### ターゲットオブジェクトの指定 (t*)

```
td
```

(set Target to Default) ターゲットをデフォルトターゲット(実装依存;通常はプレイヤー)に変更します。引数はありません。

```
tp
```

(set Target to Parent) ターゲットを親オブジェクトに変更します。引数はありません。

```
to [オブジェクトID]
```

(set Target to another Object) ターゲットを指定idを持った子オブジェクトに変更します。複数ある場合、生存している中で最古のオブジェクトになります。

## 数式

### 演算子

``` 
+ - * / %　( )
```

四則演算します。% は余剰計算です。

```
== != >= <= < >
```

比較演算します。演算結果は 1(true) または 0(false) です。

```
!
```

単項演算子で論理反転します。0→1，非0→0 という非可逆演算を行います。

```
$sin $cos $tan $asn $acs $atn $sqr $int and $abs
```

単項演算子で正弦、余弦、正接、逆正弦、逆余弦、逆正接、平方根、切捨て、絶対値を計算します。

### 変数

```
$? $??
```

乱数を返します。数値の範囲は`$?`で 0\<=n\<1、`$??`で -1\<=n\<1 です。デフォルトは Math.rand() を返しますが、`CannonML.globalVariables.funcRand` を差し替える事でアルゴリズムを変更できます。

```
$r
```

(Rank) ゲーム難易度値を返します。`CannonML.globalVariables#setRank()`で設定した値を返します。この値は、`CannonML.globalVariables#setRankRange(min, max)`で指定した範囲に丸められます。デフォルトは 0~1 です。

```
$i
```

(Iiterval) i(変遷時間)コマンドで現在指定されている値を返します。

```
$l $l1 $l2 $l3 ... $l9
```

(Loop counter) 繰り返し実行コマンドのカウンタを返します。繰り返し実行１回目では0が返り，以降繰り返した回数インクリメントされた値（最大ループ数-1まで）が返ります。また，入れ子状の繰り返し実行では，`$l1` により１階層上のループカウンタを参照出来ます（最大9階層上まで）。

```
$1 $2 $3 ... $9
```

(variable) ローカル変数を返します。CMLではオブジェクト毎に9個のローカル変数を扱えます。変数はオブジェクトに属するため、同じオブジェクトの全ファイバ（`{...}` `&` `@x` など）で共有されます。呼び出し単位（ファイバ単位・ラベル呼出単位）ではありません。そのため、同じオブジェクトで 2 つの呼び出しが重なると、後から代入・引数指定された値で上書きされます。オブジェクトが生成されると全変数は 0 になります。また，ラベル呼出で指定した引数はこれら変数に順番に格納されます。例えば，`#A{p$1,$2} &A 10,20` と記述した場合，\$1=10、 \$2=20 を返し，位置を10、20に設定します。

```
$x $y
```

(position X/Y) オブジェクトのx、y座標値を返します。

```
$sx $sy
```

(Sign of position X/Y) オブジェクトのx、y座標値の符号を返します。\$x\<0 なら \$sx=-1、\$x\>=0 なら \$sx=1です。

```
$v
```

(Velocity) オブジェクトの速度を返します。

```
$vx $vy
```

(Velocity X/Y) オブジェクト速度のx、y成分を返します。

```
$ho
```

(Head angle of Object) オブジェクトの角度を Degree 単位（スクロール方向を0、反時計回りが正）で返します。`da` で指定する値と同じ基準なので、`da$ho` で同じ向きになります。

```
$td
```

(Target Distance) オブジェクトからターゲットオブジェクトまでの距離を返します。

```
$o $o1 $o2 ... $o9
```

(Object count) `f`の第二引数でIDを指定して生成した子オブジェクトの数を返します。`$o1～$o9` で指定IDを持った子オブジェクトの数を返し、"\$o" でID指定した子オブジェクトの総数を返します。例えば，`f0,0{} f0,1{} f0,1{} f0,2{}`と子オブジェクト4個生成した場合、`$o1`=2、`$o2`=1、`$o`=3 を返します。id=0または無指定で生成された子オブジェクトの数を参照する方法はありません。

```
$p.x $p.y $p.sx $p.sy $p.v $p.vx $p.vy $p.ho $p.td $p.o $p.o1 ... $p.o9
```

(Parent) 親オブジェクトの各パラメータを参照します。`$`の後に`p.`を入れることで親オブジェクトの各パラメータを参照できます。

```
$t.x $t.y $t.sx $t.sy $t.v $t.vx $t.vy $t.ho $t.td $t.o $t.o1 ... $t.o9
```

(Target) ターゲットオブジェクトの各パラメータを参照します。`$t.td` は常に0を返します。`$`の後に`t.`を入れることでターゲットオブジェクトの各パラメータを参照できます。

### ユーザー定義変数

```
$[変数名] $[変数名]1 $[変数名]2 ... $[変数名]9
```

実装依存の変数です。プログラム内で `cml.globalVariables.registerUserVariable()` により関数を登録する事で、CML の数式の中から値を参照できます。

```
cml.globalVariables.registerUserVariable(name, func)
```

| 引数 | 説明 |
|---|---|
| `name` | CML内で `$name` と書く変数名。英数字と `_` を使えます。 |
| `func` | 参照されるたびに呼び出される関数 `func(fiber, index)`。数値を返します。`fiber` は実行中の `CML.Fiber`、`index` は変数名の直後に付けた数字（`$name` なら 0、`$name3` なら 3）です。 |

値は参照した時点で計算されます（実行時の値）。他の変数と同様に数式の中で使えます。

```
// 登録 (JavaScript)
cml.globalVariables.registerUserVariable("life", (fiber, index) => enemyOf(fiber.object).life);

// CML
[l$1=$life*2 p$1,0 w5]
```

- 変数名の末尾に数字を含めないでください。末尾の数字は `index` として扱われます。
- `$x` `$y` `$r` `$o` など、この仕様書で定義済みの変数と同じ名前は登録できません（定義済みの変数が優先されます）。
- ユーザー定義変数は、`$p.` `$t.` を付けて親やターゲットのパラメータとして参照できません。
- 登録していない名前は構文エラーです。

### 変数代入

```
l$1= l$2= l$3=... l$9=[代入値]`
```

(Let) ローカル変数に値を代入します。この変数値は、同じオブジェクトをコントロールするファイバー間で共有されます。

```
l$1+=、 l$1-=、 l$1*=、 l$1/= [計算値]
```

(Let) ローカル変数に四則計算結果を代入します。例えば、`l$1=0 [p$1,$y l$1+=10 w5]`は、位置0からスタートして、5フレーム毎に10ピクセルずつ右に動いていきます。

## ユーザー定義コマンド

実装依存のコマンド群です。

```
&[コマンド名] [引数], [引数] ...
```

実装依存のコマンドです。プログラム内で `cml.globalVariables.registerUserCommand()` により関数を登録する事で，CML内から任意タイミングで呼び出せます。

```
cml.globalVariables.registerUserCommand(name, func, argc, requireSequence?)
```

| 引数 | 説明 |
|---|---|
| `name` | CML内で `&name` と書くコマンド名。英数字と `_` (アンダーバー) を使えます。 |
| `func` | 呼び出されたときに実行する関数 `func(fiber, args)`。`fiber` は実行中の `CML.Fiber`、`args` は引数の値の配列です。 |
| `argc` | コマンドの引数の数。省略した引数は 0 になります。 |
| `requireSequence` | `true` にすると、コマンドの直後に `{...}` または `&(label_name)` が必須になります（無ければ構文エラー）。 |

呼び出し側の書き方は `&(label_name)` と同じで、引数はスペースなし（`&sound1,2`）でも、関数形式（`&sound(1,2)`）でも書けます。引数には数式を使えます。`func` を呼び出したあと、続きのコマンドをそのフレームで実行します。登録していない名前は構文エラーです。

```
// 登録 (JavaScript)
cml.globalVariables.registerUserCommand("sound", (fiber, args) => playSound(args[0], args[1]), 2);

// CML
[3 &sound $l,10 w5]
```

`requireSequence` を指定したコマンドは、直後のシーケンスを自動では実行しません。指定しない場合、直後の `{...}` は通常どおり別ファイバで実行されます。
